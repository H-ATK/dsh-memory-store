# dsh-memory-store

DeepSeek Harness 的本地记忆库 + QQ 聊天通道。

一个 SQLite 数据库，所有会话、所有工作区共用。它记录你说过什么、助手答了什么、
用过哪些工具、子代理干了什么，然后把这些整理成记忆卡，在需要的时候注入回上下文。

## 功能

### 记忆库

- **记录**：用户消息、助手回复、工具调用、子代理运行，全部进本地数据库
- **整理**：后台模型把对话折叠成"对象 / 动作 / 状态 / 细节"的记忆卡，同一件事不重复记
- **注入**：每轮对话前，按当前话题召回相关的几行，塞进上下文
- **检索**：`memory_search` 工具，模型可以主动查历史
- **关系与习惯**：记录认识多久、聊了多少轮、你习惯怎么说话
- **导出 / 导入**：整个库打包带走，换机器能接上

### QQ 通道

通过界面自动化操作真实的 QQ 客户端，不需要任何第三方协议库。

- **收发文字**：你发消息给它，它回复到你 QQ
- **收语音**：QQ 的语音是 SILK 编码，插件解码后本地识别成文字
- **两个专用会话**：「本地模型qq对话」和「付费模型qq对话」，各自保留上下文
- **自动换窗口**：会话事件数涨到 400 左右自动删旧开新
- **窗口恢复**：QQ 关到托盘也能找回，读完再藏回去，不打扰你

### QQ 命令

在 QQ 里发这些，直接回复，不经过模型：

| 命令 | 作用 |
|---|---|
| `命令` / `帮助` / `？` | 命令列表 |
| `状态` / `模式` | 当前模型、自动切换、付费槽 |
| `模型列表` | 全部本地模型和 API 模型 |
| `切换模型 <名字>` | 切过去，并设为对应的默认槽 |
| `开启自动切换本地模型` | 每轮结束切回本地 |
| `关闭自动切换本地模型` | 关掉 |
| `切回付费模型` | 回到上次的付费模型 |
| `切回本地模型` | 立刻切到本地模型 |
| `重建QQ会话` | 丢掉旧会话记录，下条消息重新建 |
| `本轮使用api` | 这一轮用付费 API，回答完切回 |

命令是固定表，精确匹配。说错了就是普通聊天，不会猜。

### 模型

- 本地模型（Ollama）和付费模型分开配置，各自一个默认槽
- 面板里点一下就能切换，切换会写进配置
- 没配槽位时，命令会问你要不要用列表第一个，回「好」就帮你选上

### 人格

决定它怎么说话、在意什么、不做什么。切换立刻生效，下一轮就用新的说话方式。

### 主动问候

按你平时活跃的时间，每天固定时刻主动说一句话。走 DSH 的定时任务投递。

## 安装

在 DSH 的插件面板里安装，或者直接放进 profile 的插件目录。

依赖：

- DSH `>= 0.2.2-rc.3`
- 可选：Ollama（本地模型）、QQ 客户端（QQ 通道）、sherpa-onnx 模型（语音识别）

## 配置

全部在插件面板里，配置存在本地数据库。主要几项：

- 机器人 QQ 号 / 你的 QQ 号 / 会话工作区
- 本地模型、付费模型
- 人格
- 主动问候时间

## 数据在哪

```
C:\Users\<你>\.dsh\storages\dsh-memory\memory.db
```

一个文件，包含所有记录。备份就是复制它。

## 已知限制

- QQ 语音消息要等 QQ 缓存落盘才能识别，第一次可能要几秒
- QQ 图片消息能收到，但本地模型是纯文本的，看不了；付费模型要看它本身支持不支持视觉
- 会话的模型在创建时绑定，切换默认模型不影响已有会话
- QQ 窗口关到托盘时，读消息需要先恢复窗口，会闪一下（无焦点）
